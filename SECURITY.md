# 安全政策及报告漏洞

[Rust 安全响应工作组](https://rust-lang.org/governance/teams/launching-pad/#team-security-response)负责处理 `rust-lang` 和 `rust-lang-nursery` 组织下所有仓库的漏洞报告与安全问题。

如果您发现了漏洞，[请按照我们网站上的安全政策进行报告](https://www.rust-lang.org/policies/security)。谢谢！

# Security Policy & Reporting a Vulnerability

The [Rust Security Response WG](https://rust-lang.org/governance/teams/launching-pad/#team-security-response) handles vulnerability reports and security issues for all the repositories in the `rust-lang` and `rust-lang-nursery` organizations. 

If you found a vulnerability please report it [according to the security policy on our website](https://www.rust-lang.org/policies/security). Thanks!
