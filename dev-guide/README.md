# Rust 参考手册开发者指南

这是参考手册开发者指南的源文件，发布于 <https://rust-lang.github.io/reference/dev-guide/>。它使用 Markdown 编写，基于 [mdbook] 构建。如果你在编辑这些页面，最佳查看方式是运行 `mdbook serve --open`。这将在 localhost 上启动一个 web 服务器，你可以访问该服务器来查看这本书；每次编辑页面时它都会自动重新加载。

本书通过 GitHub Actions 发布到 GitHub Pages。

[mdbook]: https://rust-lang.github.io/mdBook/
